# 震央地名ポリゴンデータ（jma_epicenter_regions.json）

気象庁「地震情報で用いる震央地名」の各地域が指す範囲をポリゴン化した GeoJSON
（Node の require で読むため拡張子は .json）。
`lib/epicenterRegion.js` が震央座標→震央地名（コード・地名・読み）の包含判定に使う。

- 取り込み元: [0Quake/JMA_Region](https://github.com/0Quake/JMA_Region)（Benidate）
  - 元ファイル名: `震央地名.geojson`
  - 取り込み時点のコミット: `c3a35039ff6c57ebd80f81f74037753268c4d7f9`
  - 取り込みファイルの MD5: `1e1cf35c96d7271d02c8fc044a6abe4a`（508,003 bytes、内容は無加工）
- ライセンス: CC0 1.0 Universal（パブリックドメイン）。取り込み元リポジトリの LICENSE が正本。
- データの性格:
  - 地震火山関連コード表の AreaEpicenter（震央地名コード）と対応する。331 地域、全て MultiPolygon。
  - 座標系は EPSG:6668（JGD2011）、経度は 0〜360 度表記で、本初子午線をまたぐ地域はマルチポリゴンで分割されている。
  - ポリゴンは気象庁の震央地名地図を QGIS で位置合わせし、緯経度 0.1 度グリッドを頼りに手描きされたもの（公式 GIS データではない）。境界付近の判定はこの精度に依存する。
  - 既知の元データ由来の表記ゆれがある（例: 一部英語名の誤字・末尾スペース）。日本語名・コードには影響しない。
- 取り込み時の検証（2026-11-12）:
  - コード・地名とも重複なし、欠損なし、リングは全て閉じている。地域重心での相互重なりなし。
  - このリポジトリの `tests/samples` にある気象庁 XML のうち、震央地名コードと座標を持つ 127 件全てで、包含判定の結果が電文の地名・コードと一致した。
