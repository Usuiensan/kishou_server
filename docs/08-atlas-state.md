# アトラス電文と合成状態

`createAtlasData()` が返すのは1件の電文イベントであり、画面全体の状態ではない。電文イベントは `kind` (`eew` / `tsunami` / `intensity` / `vertical`)、`action` (`upsert` / `cancel`)、`event` (イベントID・発表時刻・報数・情報種別)、`payload` で構成する。更新は同じ `kind + event.id` の状態だけに適用する。

`applyAtlasBulletin()` はイベント別の合成スナップショットへ追加・更新・取消を適用する。取消は対象の種別とイベントIDだけを消し、別レイヤーを変更しない。別地震は各レイヤー内で並行保持し、新しい発表時刻・報数の順で並べる。EEWの表示期限は既存JMAキャッシュに合わせ60秒、その他の情報は既存キャッシュ保持期間に合わせ3時間とする。期限値は受信時刻から計る。

24バイトパケットの `mode` は既存プロトコルの表示パラメーターであり、防災情報種別の選択には使わない。

## 描画配置

震度電文の説明は上部帯の震度表示領域で2ページを先に表示し、その後に既存の震度別地域一覧を表示する。各ページは7.5秒ごとに切り替える。1ページ目は発生時刻・地方名・最大震度と津波に関する文、2ページ目は震源名・深さ・マグニチュードを表示する。津波の心配なしが明示された場合はその旨を表示し、未確定の場合は沿岸への注意文を表示する。文字は既存の震度表示に合わせた白色・太い黒縁で、座布団は付けない。

津波警報・注意報がある間は上部帯を津波情報に切り替え、各予報区の警報種別、追加発表、予想高さ、到達時刻または到達状況を順に表示する。大津波警報は紫、津波警報は赤、津波注意報は黄の座布団を使う。津波情報がなくなったら震度情報の表示に戻る。

横型EEWは下段の803×268を維持する。L無効時は下段1639px領域の中央 `(715,747)`、L有効時は完成画面の中央を出力X=281から逆算した `(574.5,747)` に置く。透明度側の白枠も同じ位置に動かす。縦型EEWは左帯の安全域内 `(11,174)` に258×922で置き、地域欄の文字サイズは34px、14単位で折り返す。独立した震度見出しは隠し、震度データは上帯に表示する。津波ミニマップは下段RGB側 `(1357,651)` に579×461で置き、同じ位置の上段透明度側には対応する輝度マスクを置く。左帯にも同じ津波地図を `(11,880)` に258×205で表示し、縦型EEW表示中は隠す。上帯は震度札と地域名の間に22pxの間隔を取り、市区町村名の間を2半角空白にする。地域名は1行21文字までとし、同階級の続き行は札幅分インデントして2行ずつ切り替える。地域名と地名ルビを表示する。透明度用領域ではEEW枠全体を白くして不透明にする。津波地図は無色の海域を灰色で半透明にし、陸地・文字・警報色の区域線を白くして不透明にする。

`telop/build_atlas.py` が既存コンポーネントと `atlas-live.js` を埋め込んだ `telop/atlas-1080.html` を生成する。ページは同じディレクトリの `atlas-state.json` をHTTP経由で1秒ごとに読み、各レイヤーを独立して更新する。`atlas-live.js` の `composeAtlasView()` は描画用スナップショットを作るが、状態JSON自体は各電文イベントの合成状態であり、全画面JSONとは別物である。

津波ミニマップは `major`・`warning`・`advisory` のいずれかに区域があり、かつ `display.tsunamiMap` が `true` のとき下段RGBに表示する。`display.tsunamiLeftMap` が `true` で、縦型EEWが非表示のとき左帯にも表示する。`display.tsunamiLines` は警報色の区域線と凡例だけを切り替え、地図の下地は残す。EEW横型/縦型と地震テロップも `display` の独立した設定で切り替え、情報レイヤー自体は保持する。初期値とリセット後はすべて表示する。

ローカル試験APIの `POST /test/display` は `key` と `visible` で表示設定だけを更新する。非表示中に受信したイベントは保持し、再表示時は最新の状態を描画する。
