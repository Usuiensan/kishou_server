# 気象庁XML電文コーパス（実装・検証用の参照セット）

kishou_server の実装と検証に使う、気象庁防災情報XMLの静的な参照データ。
本番サーバーが受信電文を自動保存するアーカイブ（サーバー上の `runtime/jma-xml/`）とは**別管理**で、
こちらは人が選んで固定したデータセットである。自動アーカイブの電文がここへ混ざることはない。

## 中身

### feed-eqvol_l-20261116-20261123/（444件・約9.3MB）
- 2026-11-23 に気象庁開発者向け長期フィード `https://www.data.jma.go.jp/developer/xml/feed/eqvol_l.xml`
  から取得した実電文の全件（2026-11-16〜2026-11-23 の8日分）
- 種別: VXSE51/52/53/61/62、VFVO51/52/53/60 ほか。全て Status=通常・InfoType=発表
- 実測値（アーカイブ容量設計の根拠）: 対象種別（VXSE・VTSE 全種別＋VFVO51/52）は約0.083MB/日、
  VFVO53（火山の定期解説）だけで約1.06MB/日と全体の9割超を占める

### public-samples/（166件）
- 公開サンプル集 [kpherox/JMA-XML-SampleData](https://github.com/kpherox/JMA-XML-SampleData)
  （気象庁の電文フォーマットサンプル）から、地震・津波・火山系だけを抜粋したもの
- 実フィードの8日分には無かった **取消（11件）・訂正（1件）・訓練（2件）・試験（1件）** を含む
- 旧形式の種別（VXSE40/41、VTSE40/50、VFVO50 等）も含む

## 使い方
- パーサや取り込み処理の回帰確認、表示の再現テストの入力として使う
- 取消・訂正・訓練・試験の扱いを変えるときは public-samples 側の該当電文で確認する
- 日常のテスト用サンプルは従来通り `tests/samples/` と `demo-fixtures/` を使う（このコーパスは全件走査の対象にしない）

## 出典
- 気象庁防災情報XML（気象庁ホームページの利用規約および防災情報XMLの提供条件に従う）
