# 伊豆諸島（320）固定色帯レビュー

## 成果物

- `regions.json`: 注意報・警報・大津波警報の固定領域。座標は640×510 viewBox。
- `advisory-solo.png` / `warning-solo.png` / `major-solo.png`: 各種別の単独画像。
- `advisory-adjacent.png` / `warning-adjacent.png` / `major-adjacent.png`: 近接6区域の海岸帯を青、伊豆諸島を種別色で重ねた画像。
- `contact-sheet.png`: 460px幅で6画像を並べた縮小確認用。
- 再生成: `python telop/build_izu_regions.py`（ImageMagick が必要）。

## 入力と作成方法

- 気象庁の津波予報区線は、リポジトリの `telop/tzones.js` を `telop/build_art.js` で変換した `telop/tsunami-art.js` のコード320を使用。
- 陸地は同じ現行描画データの `landMain` / `landInset` を使用。これらは `telop/geojson.js` から `telop/build_land_components.py` が作る `telop/land_components.json` を描画変換したもの。
- 現行ビルドで保持された伊豆諸島の10海岸線ループそれぞれに、海側へ法線オフセットした外周と元海岸線を組にした固定領域を作成。陸側は現行の陸地塗りで覆う。注意報・警報は2.4px、大津波警報は4.7px（viewBox基準、約1.96倍）。
- 元の `tzones.js` にはコード320の12線があるが、現在の描画ビルドでは10線が保持されている。極小島の省略方針に合わせて現行の10線を採用した。どの省略線がどの島に対応するかは未照合。
- 固定領域は候補・確認用として別ファイルに保存し、全国描画や本番送出へ接続していない。

## 検証

- ImageMagick で各SVGプレビューを460×367pxへラスタライズし、6枚と一覧画像を生成。縮小一覧で島列の連続性、色の視認性、隣接帯との距離を目視確認。
- 隣接区域は気象庁の区分と変形後の近さから、310、311、312、321、330、380を選択。現行陸地マスクの外側（海面）で、伊豆諸島の帯と6区域の帯が交差する画素を別々のマスクで計数。640×510及び460×367の両解像度で、3種別すべて0画素。
- 根拠: [気象庁・予報区等GISデータ一覧](https://www.data.jma.go.jp/developer/gis.html) は津波予報区のGIS ZIPを掲載し、津波予報区データの更新履歴は2024-05-20。掲載ページが説明するデータは海岸線情報で、海上の区域を囲う公式ポリゴンではない。[津波予報区の説明](https://www.jma.go.jp/jma/kishou/know/jishin/joho/tsunami-yohoku.html) では伊豆諸島を大島・三宅・八丈支庁とし、隣接区分を示す。

## 未確認事項

- 海岸線GISは海上の区域境界ポリゴンを含まないため、色帯の海側端が公式な海域境界内にあることまでは証明できない。確認したのは沿岸線からの限定幅と、上記6近接区域との帯の非交差。
- `geojson.js` の陸地データに対する位置合わせは現在の描画出力との整合で確認した。国土地理院の最新配布物との再照合はしていない。
- 10本の保持線での縮小表示は確認したが、省略した2線の島名・位置への影響は別途照合が必要。
