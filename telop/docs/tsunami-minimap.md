# 津波ミニマップ (画面右下・透過) — tsunami.html

気象庁の津波警報等「発表図」の様式を、放送画面の右下に重ねる小サイズ前提で再現したコンポーネント。

## 様式の根拠
- 種別色は「全テレビ局で統一」された業界基準の推奨値 (伊藤啓・カラーユニバーサル
  デザイン機構が放送局と策定し、NHK・民放連が合意。2011年5〜8月に各局移行):
  大津波警報=紫 (200,0,255)、津波警報=赤 (255,40,0)、津波注意報=黄 (250,245,0)。
  気象庁の自社HP向け配色指針 (2012年、2020年改訂) もほぼ同色。
  - 純赤 (255,0,0) はP型色覚で暗く沈むため橙寄り、黄は白内障配慮で僅かに暗くする。
  - 大津波警報のライン幅は他2種の約2倍 (色だけに頼らないための冗長化)。
  - 陸地は灰 (213,213,217)。透過時は海を無色透明にし、輪郭線でラインと陸地を分ける。
  - 出典: https://jfly.uni-koeln.de/color/tsunami/ 、
    https://www.jma.go.jp/jma/kishou/info/colorguide/HPColorGuide_202007.pdf
- 初版はユーザーが提示した使用例図からの目測 (#ff00ff/#ff0000/#ffff00) で作り、
  調査結果を受けて上記の統一値に差し替えた。
- デフォルメ (気象庁使用例に合わせた):
  本土は縦方向に 0.93 倍へ潰す。沖縄・小笠原は本土へ寄せて置く。
  小さい島は実寸では潰れて読めないため、地物単位で誇張する
  (本土の小島 ×1.8、沖縄 ×1.7、小笠原 ×2.0。陸地と区域線で同じ錨と倍率)。
  伊豆諸島は半島の南沖に短い列として並べ直し、×3.2 に誇張する。
  小さい島は、所属区域が発表中なら発表色でベタ塗りにする (使用例の丸い島)。
- 画面右下ミニマップの出し方は、ユーザーが提示した放送のお手本 (実写) に合わせた:
  陸地は白ベタ+黒い海岸線 (県境なし)、沖縄・小笠原は枠なし。
  沖縄の分離線は「島々の下を横に走り、右端で斜めに上がって短い縦線」。
  ラベルは左上。小笠原は角ブラケット「┌」 (上バー+左の脚) で、ラベルは脚の右。
  凡例は種別ごとの縦列 (色チップ+縦書き種別名、列自体が黒箱) を横に並べる。
  地図とは重ならないよう、本土パネルを左へ寄せて右端に凡例の幅を空けてある。
- 発表区域の色線の点滅は、実放送の実測値: **周期3秒、点灯 約2.25秒 / 消灯 約0.75秒**。
  実測方法: 2025-07-30 のNHK津波警報放送 (YouTube rm3lzNpvE0I、320x240/30fps) の
  ミニマップ領域を切り出し、100〜140秒の1200フレームで赤・黄ピクセル数を数えた。
  両色とも点灯67〜68フレーム / 消灯23フレームの矩形波で、位相も一致 (周期90フレーム=3秒)。
  別の実放送 (Bilibili BV1JyhczcEjP、同イベントのNHK完全版録画) でも再解析し、
  点灯65〜69 / 消灯22〜25フレーム (30fps換算) で一致を確認した。
  当初はユーザー指定の 1秒 on / 0.5秒 off で実装し、実測を受けて差し替えた。
  `blink:false` で常時点灯にもできる。

## データ
- 海岸線: 気象庁「予報区等GISデータ」の **津波予報区** シェープファイル
  (https://www.data.jma.go.jp/developer/gis/20240520_AreaTsunami_GIS.zip、89MB)。
  もともと区域ごとの海岸線ポリライン (66区域+帰属未定4件) で配布されている。
- 加工: 帰属未定を除き、shapely で 0.008° 簡略化+短い破片を除去し、
  `tzones.js` (66区域、8,072点、136KB) に変換。生成元は ~/workspace/tsunami-zones/ に保存。
- 陸地: 既存の geojson.js (都道府県ポリゴン) を流用。

## API
`renderTsunamiMini({ major:[], warning:[], advisory:[], legend:false })`
- 配列要素は予報区名 ("岩手県") でも気象庁コード (210) でもよい。
- 同じ区域が複数種別に現れたら強い順 (大津波警報>警報>注意報) で描く。
- URL: `?demo=example|tohoku|advisory_all|none`、`?custom=<JSON>`。
- テスター単一ファイルは `python3 build_tsunami_tester.py` で再生成する。

## レイアウト実測合わせ (2026-11-09、使用例 7680×4320 をピクセル計測)

使用例の実測 (本土 bbox x1767–5844 / y527–3781 に対する比率):
- 沖縄の分離線: 縦線 x≈0.475 (y 0.145–0.44)、斜線は傾き dy/dx≈0.53 で浅く長く、水平部 y≈0.554 で西端は本土西端付近まで。奄美〜本島の塊は x 0.19–0.45 / y 0.11–0.39 と本土の西岸に沿って斜めに大きく、縦線はその東に接する。宮古・八重山は x 0.00–0.15 / y 0.44–0.53、ラベル「沖縄」はその東・水平部の上で、列島の下に収まる。
- 小笠原: バー y≈0.818、x 0.39–0.60。脚はラベルの下端より少し下まで。島の塊はバーのすぐ下 (上面がバーに接する) にある縦長の瓢形で、高さは本土の高さの約7.6%。ラベルは塊の右下、字高は本土の高さの約7.4%。

## NHK実放送フレームへの登録 (2026-11-09、v15)

ユーザーが送った NHK 実放送スクリーンショット (1023×815) に完全に重ね合わせられることを目標に再設計した。v14 の MLS (移動最小二乗) は地形を局所的に溶かす変形で、実放送の歪み方とは別物だったため廃止。

- 基準フレームの白陸マスクを連結成分解析し、北海道塊 (x562–809, y53–234)・本州塊 (x148–654, y252–605)・四国塊・九州塊の極点から 11 ランドマークを実測: 宗谷 (656,53)・納沙布 (809,152)・襟裳 (714,208)・下北 (585,252)・岩手東 (654,325)・紀伊 (364,605)・山口西 (148,574)・足摺 (232,649)・室戸 (318,607)・九州西 (110,612)・佐多 (161,703)。
- 本土の変形は全体アフィンのみ: x' = 1.3445x − 0.0203y − 182.38 / y' = 0.0732x + 1.1385y − 31.86 (基礎投影の出力空間→viewBox)。実質は横 ×1.34・縦 ×1.14 の引き伸ばし + 微回転で、地形の局所形状は保たれる。残差は平均 10.0 / 最大 20.4 (viewBox px、フレーム換算 平均 16px)。2次曲面化しても 平均 9.2 と大差なく、過適合を避けてアフィンを採用。
- viewBox を 640×510 に変更し、フレーム (1023×815) とアスペクトを一致させた (×0.6256 で座標換算)。
- 仕切り線 [[255,122],[255,294],[203,318],[36,318]]、小笠原ブラケット [[223,502],[223,442],[333,442]]、ラベルは沖縄 (66,306) 36px・小笠原 (243,506) 34px。凡例は左端 x386・列幅 48・チップ y230・文字 30px (いずれもフレーム実測換算)。
- 別枠の表示規則 【2026-11-09 訂正】: 当初「発表がないとき沖縄・小笠原の陸地は表示されない」と読んだが誤り。ユーザー提供の別フレーム (2022-01-16 の拡大画) で、沖縄・小笠原とも発表がない状態でも列島・島の陸地が描かれていることを確認した。陸地は常時描画し、区域線だけが発表時に付く。`gate` は撤去済み。
- 検証状況: Node 上でコンポーネントを実行し、viewBox・宗谷の着地誤差 3.7px を確認済み。ゲート撤去後は demo=none でも陸地 path が 1155 (別枠込み) になることを再計測で確認。
- 目視重ね合わせ確認 (2026-11-09、環境復旧後に実施): Chromium で実ページを撮影し、基準フレームへ screen 合成。本土の陸地はフレームの陸地に重なる (アフィン fit の数値残差と整合)。一方、装飾の初期値 (目視読み) は実測とずれていたため、フレームの成分分析で再測して修正した: 沖縄ラベル (66,306)→(133,272)、小笠原ラベル (243,506)→(315,492)、小笠原ブラケット [[223,502],[223,442],[333,442]]→[[256,499],[256,411],[373,411]]。修正後の重ね合わせで両ラベルがフレームのラベルに重なることを目視確認。沖縄の分離線はフレーム上で断片化して成分として再測できず、初期の目視読みのまま (未検証として残る)。
- 要素衝突の修正 (2026-11-09、ユーザー指摘): 本土パネルが薩南諸島 (トカラ列島) を実位置にも描いていたため、列島が仕切り線を越えて inset と衝突し、九州南西にも色が積み重なっていた。原因は本土の除外条件が北緯29.05度までしか効かず、窓のマージンで 29.6 度付近の島が本土側に入っていたこと。対策: 本土の除外を (lon<131.3 かつ lat<31.05) へ広げ、沖縄パネルの緯度上限を 31.2 度へ上げて種子島・屋久島ごと inset 側へ寄せた。あわせて inset の区域線スケールを 2.0/1.8 → 1.2 に下げ、島が線に埋もれないようにした。修正後の描画で列島が仕切り線を越えず、九州南西の積み重なりも解消したことを目視確認。
- 仕切り線と小笠原の追加修正 (2026-11-09、ユーザー指摘): (1) 沖縄パネルの東端 (経度131.2度) が種子島をパネルのクリップ端＝仕切り線の真上に置いていたため、パネルの経度上限を 132.4 度へ広げ、列島全体を西へ寄せて仕切り線との間に海の間隔を作った。(2) 小笠原ブラケットの中に島が見えなかったのは3つの重なり: パネル位置 (205,438) が v15 で再測したブラケット (256,411)–(373,499) とずれていた、パネルの除外条件が硫黄島を消していた、海岸下地を区域線から描いており拡大中心のずれで小さい島の白い陸地が下地に食われていた。対策: パネルをブラケット内側 (262,417,105×76) へ移し、除外を撤去し、別枠の下地は陸地パス自身から描くよう変更 (位置が完全一致する)、島の拡大率を 2.8 → 4.2 へ上げた。修正後、ブラケット内に父島列島と硫黄島が入り、発表時は区域色がその上に乗ることを目視確認。

## 固定画方式への作り直し (2026-11-09、v16)

v15 までの「パネル別プロジェクタ + 経緯度窓での振り分け + 地物ごとの拡大」は、継ぎ目ごとに新しい衝突 (列島が仕切り線を越える、線が島に当たる、小笠原ブラケット内が空) を生み続けたため廃止。実物のCGと同じ構造に作り直した。

- **ビルダー** `build_art.js` (Node): geojson.js + tzones.js から最終座標 (viewBox 640×510) に焼き込んだ `tsunami-art.js` (260KB) を生成。実行時に投影・振り分け・拡大は一切しない。
  - 本土: 従来のプロジェクタ + 全体アフィン (v15 の fit をそのまま焼き込み)。伊豆の並べ直しも焼き込み済み。
  - 列島 (薩南・琉球): 単一の相似配置。アンカー (131.0°E, 31.4°N)→(246, 142)、(123.0°E, 24.5°N)→(66, 288)。仕切り線の内側に全体が収まる。
  - 小笠原: ブラケット内 (262, 417, 105×76) への単一配置。経度 143.5 以東の地物 (南鳥島) は画に入れない。沖ノ鳥島・南鳥島の点ポリゴンは塵として除去 (陸地: 最大辺 0.02° 未満か最小辺 0.0015° 未満。区域線: 真の点セグメントのみ)。
  - 島の誇張は「島グループ」(中心 0.12° 以内で連結) 単位で陸地と区域線が中心を共有。列島は全島にテーパー倍率 (最大辺 1.2° で 1.0、0° で 2.2) を適用し、倍率の崖をなくした。
- **描画** `tsunami.html`: 焼き込みパスの再生専用。下地 (別枠は陸地パス自身の暗ストローク、本土は区域線の黒)、陸地ベタ、発表区域線、装飾、凡例の順。色・点滅 (3秒周期)・凡例・API は v15 から不変。
- **検証** (全体を1枚で判定): 発表なし/使用例デモを暗背景で通し描画し目視 — 衝突・越境・空のブラケットいずれもなし。実フレーム (image-25) へのスクリーン合成では本土が従来の fit 残差の範囲で一致。
- 残る留保: (1) 沖縄の分離線の位置はフレームから再測できておらず初期の目視読みのまま (未検証)。(2) 「沖縄」ラベルは実測位置のままで、沖縄本島の南西半分はラベルの背後に来る (実物もラベルを地物の上に置く様式)。
